# Настройка и запуск проекта

## 1. Настройка окружения (`.env`)

Создайте файл `.env` в корневой директории проекта и укажите переменные для автоматического создания администратора:

```env
ADMIN_EMAIL=test@mail.com
ADMIN_PASSWORD=securepassword
````

> **Примечание:** Если эти переменные не заданы в `.env`, система автоматически использует значения по умолчанию:
>
> * **Email:** `test@mail.com`
> * **Password:** `securepassword`

## 2. Быстрый запуск (Docker Compose)

Запустите сборку и старт всех сервисов одной командой:

```bash
docker compose up --build -d
```

При первом запуске сервер автоматически:

* применит все миграции базы данных SQLite;
* создаст первичные роли и статусы воронки;
* создаст аккаунт администратора с указанными в `.env` данными.

## 3. Доступ к сервисам

После запуска сервисы будут доступны по следующим адресам:

| Сервис                   | Адрес                        |
| ------------------------ | ---------------------------- |
| **Веб-интерфейс (CRM)**  | `http://localhost:3000`      |
| **CRM в локальной сети** | `http://<IP_ВАШЕГО_ПК>:3000` |
| **Backend API**          | `http://localhost:8080/api`  |
